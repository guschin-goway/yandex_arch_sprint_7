## 1. Выбор эмбеддинг-модели

### Выбранная модель

**all-MiniLM-L6-v2**

### Обоснование выбора

Модель **all-MiniLM-L6-v2** оптимально подходит для использования в рамках RAG-бота по следующим причинам:

- подходит для **локального использования** без необходимости обращения к облачным сервисам;
- обеспечивает **быстрое прототипирование** и удобна для экспериментов;
- хорошо масштабируется для **небольших и средних корпоративных баз знаний**;
- может эффективно работать **без GPU**, используя только CPU;
- широко применяется в практических RAG-проектах и имеет стабильное сообщество.

Модель демонстрирует хорошее соотношение **качества семантического поиска** и **скорости работы**, что критично для интерактивного бота.


### Характеристики модели

- **Название:** all-MiniLM-L6-v2  
- **Тип:** Sentence Transformers  
- **Размер эмбеддинга:** 384  
- **Язык:** мульти-язычная (хорошо работает с русским языком)  
- **Формат:** dense embeddings  
- **Лицензия:** Apache 2.0 (подходит для коммерческого использования)
